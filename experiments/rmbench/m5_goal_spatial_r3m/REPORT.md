# M5 下一关键状态辅助监督 · RMBench 方块覆盖

M5 保留 M4 的连续历史、事件写入淘汰、交叉注意力和扩散动作网络。用于重构过去动作的辅助头改为预测下一关键帧视觉表征；预测使用的潜在向量也直接送给动作头。

目标来自官方语言标注，同一事件内的相邻动作描述先合并。已核对 50 条示范的关节和动作数组以及各事件起止图像。最后一张原始采集图像依照官方转换规则作为前一帧的动作来源。每个事件用最后一张有效 RGB 形成目标，只有前半段的锚点使用目标损失。
冻结官方 R3M-ResNet18 从 layer4 生成 3×3 个 512 维位置表征，每个位置分别归一化。
参见 [标注统计](annotations/statistics.json) 和 [复现步骤](README.md)。

种子 0 达到 40% 门槛。按用户安排，种子 1 暂缓。
