# 关键帧人工抽查与自动审查

全部 50 条专家示范的关节状态和动作数组与官方归档逐项一致。官方采集计数包含终帧，XPolicyLab 转换用采集帧 t 的 RGB 和关节状态、采集帧 t+1 的关节值作为动作。因此配对数据的 RGB 区间从 0 起，只有采集终帧没有配对 RGB；原始 51,127 帧产生 51,077 个训练配对帧。核对了每个事件的起始、中间、候选完成帧与实际所选帧。

候选状态先按同一连续语言标注合并。对原生 RGB 确认固定相机及初始颜色排列，并在归档 RGB 内核对盖子就位、方块露出或被遮挡，以及操作侧夹爪已经打开。要求三个相邻帧均通过。默认用候选完成帧，若缺少证据则在事件后半段向前找最近稳定位姿；找不到时关闭该事件的辅助标签。该审查使用的是专家图像和关节记录，图像证据不等同于仿真器的精确物体坐标。300/300 候选均通过，均保留事件末尾的有效 RGB，25,478 个训练锚点参与空间视觉监督。标注器里的台面位置检查只用于 Cover Blocks 的离线完成核验。

所有 50 张图像摘要保存在服务器 experiments/rmbench/m5_goal_spatial_r3m/annotations/keyframes/。每行包含开始、中间、原候选、目标前一帧、目标和目标后一帧。配对 RGB 中不存在目标后一帧时显示空白。抽查了示范 0、17、49，画面中的遮盖、揭盖和逐阶段状态与对应索引一致。
