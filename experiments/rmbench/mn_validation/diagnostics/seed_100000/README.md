# 方块覆盖首次揭盖诊断

M3 第 100 轮检查点以原双环境批次重放种子 `100000`。第 451 步完成遮盖，第 630 步先揭开绿块盖子。正确目标是中间的红块。[重放对齐](replay_alignment.json)

| 检查 | 结果 |
|---|---|
| 初始槽投影后的红块位置读出 | 留出的真实布局对照 24/24 |
| 完整投影的读出 | 同一时刻匹配背景时 44/44；训练与测试时刻分开时 4/44 |
| 固定观测、循环状态和扩散噪声，只替换早期记忆中的红块位置 | 22 个预测时刻中，预测末端位置最大变化 0.09 毫米，动作仍指向绿块盖子 |
| 固定条件，替换初始槽投影为真实布局对照 | 最大关节角差 0.000123 弧度 |

44 次读出来自同一条轨迹的 22 个预测时刻和两折读出。结果表明，本回合情景记忆中的位置线索经投影后仍可读出，但跨时刻读出不稳定，改变线索也几乎不改变首次揭盖的动作。该诊断固定了 Mamba 循环状态，范围限于这一个检查点和回合。
