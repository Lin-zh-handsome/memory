# RMBench 多事件记忆实验结果

电池试插完成 500/500 回合。方块覆盖在用户要求下停于 458/500 回合。两个任务的 M0 和 M3 均完成 250 轮训练。固定训练种子 0，每个检查点计划评测 50 回合。

| 检查点 | 方块覆盖 M0 | 方块覆盖 M3 | 电池试插 M0 | 电池试插 M3 |
|---:|---:|---:|---:|---:|
| 50 | 6/50（12%） | 8/50（16%） | 11/50（22%） | 23/50（46%） |
| 100 | 8/50（16%） | 9/50（18%） | 24/50（48%） | 43/50（86%） |
| 150 | 6/50（12%） | 6/50（12%） | 41/50（82%） | 46/50（92%） |
| 200 | 8/50（16%） | 8/50（16%） | 40/50（80%） | 47/50（94%） |
| 250 | 3/50（6%） | 1/8（提前停止） | 43/50（86%） | 47/50（94%） |

方块覆盖完整检查点最佳成绩为 M0 16%、M3 18%。电池试插最佳成绩为 M0 86%、M3 94%，M3 在第 200 与第 250 轮并列。
