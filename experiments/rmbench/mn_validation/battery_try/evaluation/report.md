# RMBench battery_try 单种子闭环验证

任务为 battery_try，配置为 demo_clean，训练种子为 0。M0 和 M3 各计划训练 250 轮，在同一组 50 个官方环境初始条件上评测五个检查点。两组成绩取各自五个检查点中的最高成功率，同分取最早检查点。

已固定 50 个有效测试初始条件。[初始条件清单](reset_seeds.json)

M0 的最佳检查点为第 250 轮。[检查点](../checkpoints/M0/epoch_250.pt)
M3 的最佳检查点为第 200 轮。[检查点](../checkpoints/M3/epoch_200.pt)
M3 的最佳成功率比 M0 高 8.0 个百分点。
