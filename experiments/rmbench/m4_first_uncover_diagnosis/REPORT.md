# M4 首次揭盖与情景记忆诊断

使用原 M4 第 250 轮、训练种子 0 和固定环境种子 100000–100049。权重、写入、训练损失和正式记录沿用原实验。

## 官方条件与实际失误

RMBench 要求从左到右盖上三个方块，再按红绿蓝揭盖。只有盖子处于允许的落点时才接受状态变化，非预期变化会置失败标志。左绿、中红、右蓝时，合法序列为 000 → 100 → 110 → 111 → 101 → 001 → 000。
正式轨迹中，50/50 盖齐，28/50 首次揭对，16/50 完整成功。22 回合在首次揭盖阶段触发顺序错误，12 回合首次揭对后仍发生顺序错误。首次揭对后有 12 回合最终失败。
原动作重放中 50/50 与正式阶段序列、终止步和成功标记逐项匹配。50/50 恢复了物理起盖时刻；有唯一官方首次盖子且有物理定位的 50 回合中，50 个定位到同一盖子，50 个在 5/10/15 毫米阈值下保持该物理目标。盖齐后首次预测距首次物理起盖的中位间隔为 127.000 步。
起盖时刻定义为盖子持续三步抬高超过 10 毫米且工具点位于抓取邻域的第一个环境步。官方状态确认还要等待盖子落到合法位置，二者分开记录。缺少可靠起盖证据的回合保留空值。
另有 50/50 回合可从已确认的抬盖向前定位闭爪动作。以工具邻域内夹爪指令从全开开始持续下降为依据。

E0 权重最高次数为 [0, 17, 31, 42]，最近事件权重最高次数为 [0, 0, 0, 0]。四头共同选择同一槽有 0 回合，共同选择最新槽有 0 回合。
有至少一头把 E0 排首位时，最终读出猜对 42/50，真实首次揭对 28/50。
起盖前，共 50 回合。四头 E0 中位权重为 5.74%, 0.45%, 15.17%, 22.71%。

注意力记录含查询、各槽的键和值、缩放后的注意力分数、有效位、时间索引和相对年龄。原始点积是缩放分数的 8 倍。高权重自身只描述加权强度。

## 短程闭环

目标编号 0、1、2 依次对应左、中、右。

尝试 4 个受体、8 次事实回放。4 次回放复现原始首次揭盖的目标与时刻。在 4 次合格异位置分支中，3 次换盖，其中 2 次选中供体目标。原轨迹已经揭对的分支中，有 1/3 次替换后选对供体目标。同位置对照保持原实际目标 4/4 次。
闭环分支从同一个经对齐的全遮盖前缀开始，在每次预测时替换 E0 内容，正常更新其余记忆和环境。固定状态和噪声的离线单步比较与开始执行后可分化的闭环轨迹分别解释。

## 结论与优先项

| 问题 | 判定 |
|---|---|
| 首次揭盖执行偏差 | **已验证。** 所有回合都盖齐，首次揭对与最终成功之间还相差 12 回合。错误集中于揭盖顺序。 |
| 写入是否保存首帧位置 | **已验证可解码。** 该时刻 E0 为 50/50。其他关键事件是否漏写待验证。 |
| 键／值投影是否明显损失 | **已验证可解码性。** 键 50/50，值 50/50，以同组原始 E0 为参照。 |
| 注意力加权与输出投影 | **已验证可解码性变化。** 四头拼接 25/50，最终读出 24/50。是否读到了当前动作真正需要的事件还需结合分支。 |
| U-Net（去噪网络）是否使用记忆 | **已验证固定输入下的动作敏感性。** 是否选对替换后的盖子以合格闭环分支为准，离线变化幅度只描述单动作块。 |
| 操作阶段判断或控制是否是根因 | **待验证。** 轨迹确认了物理起盖到状态确认的时差与失败阶段。当前诊断没有单独干预控制器。 |

优先检查**注意力读取**。首帧值仍能解码，主要下降出现在聚合时。优先确定第一次趋向错误目标之前的读取过程，再比较相关注意力头的值与加权，并以真实目标切换验证。闭爪前的读出可能已反映先前的选择。现有证据支持保留写入规则；时间编码与动作头的独立贡献仍待验证。
